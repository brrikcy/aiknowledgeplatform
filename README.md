# Knowledge AI Platform

Self-hosted AI knowledge platform that allows organizations to upload internal documents and query them using LLM-powered semantic search (RAG).

## Goals

Build a local-first AI system capable of:

- Document ingestion
- Semantic search
- Retrieval Augmented Generation (RAG)
- AI agents for knowledge interaction

## Tech Stack

Backend:
- FastAPI
- Python

Database:
- PostgreSQL (planned)

Vector Database:
- Qdrant (planned)

AI:
- Sentence Transformers / OpenAI embeddings
- LLM integration

Infrastructure:
- Docker
- Local deployment
